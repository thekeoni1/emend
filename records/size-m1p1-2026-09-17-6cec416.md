## Reading these figures

File sizes on this target change in whole 4096-byte steps. They are not
themselves whole pages: all five probes leave the same remainder, 2596 bytes,
modulo 4096, so it is every DIFFERENCE between them that is a whole number of
pages. A change under a page is therefore invisible in the file size, and a
change of a few thousand section bytes can cost more than one page: the
committed duplicate check costs
5016 section bytes and 8192 file bytes in `probe-emend-edit`. The section
totals, from `size -A`, resolve to the byte, which is why both are given.
