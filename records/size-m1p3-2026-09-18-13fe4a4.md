## The float parser's own cost

`specs/0010-reading-cells.md`, "Size", asks for this figure to be measured
rather than guessed. A variant of `probe-emend-cells-xml` was built in a

## Reading these figures

File sizes on this target change in whole 4096-byte steps. They are not
themselves whole pages: all eight probes leave the same remainder, 2596 bytes,
modulo 4096, so it is every DIFFERENCE between them that is a whole number of
pages. A change under a page is therefore invisible in the file size, while
the section totals, from `size -A`, resolve to the byte. Both are given for
every figure above.
