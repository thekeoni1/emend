# Size, Milestone 2 part 4d: 2026-10-01-c1f6602

The stripped `i686-unknown-linux-musl` sizes of the twenty-one size probes,
measured by `records/logs/m2p4d-p4/size.log` after Milestone 2 part 4d,
comments and images (`specs/0022-comments-and-images.md`, "Size", under
decision 1 taken as A). The part's capabilities are behind the Cargo
features `comments` and `images`, off by default and outside the core;
their costs are measured by `probe-emend-comments-write-xml` and
`probe-emend-images-write-xml` beside the core probe. The budget is the
core probe, `probe-emend-format-write-xml`, over `probe-zip-xml`, against
the Milestone 2 ceiling (`specs/0017-fuller-styles.md`, decision 1, A),
which this part does not move by design. This record follows
`records/size-m2p4c-2026-09-30-3c5f0b7.md`, part 4c's, which stands as history.

## Reading these figures

File sizes on this target change in whole 4096-byte steps. They are not
themselves whole pages: all nineteen probes leave the same remainder, 2596
bytes, modulo 4096, so it is every DIFFERENCE between them that is a whole
number of pages. A change under a page is therefore invisible in the file
size, while the section totals, from `size -A`, resolve to the byte. Both
are given for every figure above.
