# 0051: Milestone 9 part 1, the minimum Rust version

Status: APPROVED 2026-11-14 (the maintainer, typed in the planning

found by trial, declared, and tested in CI.

This moves an earlier decision. `specs/0029` decision 1 (Milestone
3 part 7) set `rust-version` equal to the toolchain pin and left
"the oldest compiler the crate builds with, found by trial" as its
option B, outside that part's size. This part is that option B for

tools, the size records and CI's `check` job.

## Goal

1. `crates/emend` declares the lowest `rust-version` at which it
   builds and its tests pass, with no feature and with every
   feature, on the host and on `i686-unknown-linux-musl`.
2. A CI workflow tests that version on every push.
3. The README says which Rust the crate needs.
4. No source file of the crate changes. The floor is where today's
   code builds; a build error at an older version is the reason
   the floor is not lower, never a reason to edit code. The size
   budget figure stays 456248, a difference a FINDING.

## Facts at approval (HEAD e1d8fc7)

Printed by `cargo metadata --locked --offline` over the crate's
normal and build dependencies: 12 packages. The highest
`rust-version` among the 11 that are not emend is 1.88 (zip
8.6.0); quick-xml 0.42.0 declares 1.86, hashbrown 0.17.1 and
indexmap 2.14.2 declare 1.85. The floor is therefore 1.88 at the
lowest, and 1.98 at the highest.

## The trial (P1)

`V` is a minor version written `1.N`. A trial of `V`:

- `rustup toolchain install 1.N --profile minimal --target
  i686-unknown-linux-musl`, then `rustc +1.N --version`, printed.
  This spec is the recorded decision `specs/0001` asks of an
  install. `rust-toolchain.toml` does not change, and no trial
  runs with `RUSTUP_AUTO_INSTALL` unset after the install line.
- eight commands, each with `--locked` and `-p emend`: `cargo
  +1.N build` and `cargo +1.N test`, with no feature flag and
  with `--all-features`, on the host and on the i686 target, the
  i686 tests run as the gate runs them for the pin.
- `V` passes when all eight exit 0 and each test command's counts
  of tests run equal the pin's for the same command, printed side
  by side. A failed command's first error line is printed.

The search: try 1.88. If it passes it is the floor, and the log
prints by `grep -n` the `rust-version` line of zip 8.6.0's
manifest in the registry source as the reason 1.87 is not tried.
If it fails, bisect between 1.88 and 1.98 (1.98 is the pin and is
not tried); the floor is the lowest passing `V` whose next lower
minor failed, both trials in the log. Each trial runs once. A
failure is a result of the search and is recorded, never rerun.

Each trial uses its own target directory under the phase's
scratch, so no trial reads another's or the gate's build output.

P1 changes no file outside `records/logs/m9p1-p1/`.
