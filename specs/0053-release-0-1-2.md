## The equal-bytes proof (P1)

Two parts, both in the logged run.

1. The source. `git diff v0.1.1..<release commit>` over
   `crates/emend/src` and `crates/emend/template` is printed with
   `--stat`, and the count of changed lines that do not begin
   `//!` is 0. A control plants one code line in a scratch clone
   and the count reads 1.
2. The outputs. A clone of the tag `v0.1.1` and a clone of the
   release commit, both under the phase directory, each run
   `cargo test -p emend --all-features --locked` on the host and
   on `i686-unknown-linux-musl` with `EMEND_KEEP_DIR` set to its
   own empty directory. For each target the two kept sets are
   compared: the same file names, the same count, the same
   sha256 for every file. The log prints the count and one
   sha256 over the sorted list of each set. A file in one set
   alone, or a file whose sha256 differs, is a FINDING and a
   stop. A control changes one byte of one copied file and the
   comparison names that file. A count of 0 is a failure.

The kept files are generated by the tests and hold no private
content. Their names are printed; the corpus is not used.
